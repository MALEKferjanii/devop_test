┌───────────────────────────────────────────────────────────────────────────┐
│ 🔧 TROUBLESHOOTING                                                        │
└───────────────────────────────────────────────────────────────────────────┘

  Service not starting:
    → docker-compose logs [service-name]
    
  Port already in use:
    → Change port in docker-compose.yml
    
  Kubernetes pod not running:
    → kubectl describe pod [pod-name]
    → kubectl logs [pod-name]
    
  Jenkins can't access Docker:
    → docker exec -u root jenkins chmod 666 /var/run/docker.sock
    
  Can't connect to database:
    → Check MySQL is running: docker ps | grep mysql
    → Test connection: docker exec -it tpfoyer-mysql mysql -u root -p
    
  SonarQube won't start:
    → Increase Docker memory to 4GB+
    → Check logs: docker logs sonarqube

┌───────────────────────────────────────────────────────────────────────────┐
│ 📈 NEXT STEPS                                                             │
└───────────────────────────────────────────────────────────────────────────┘

  1. Configure Jenkins:
     - Install plugins (SonarQube, Nexus, Docker, Kubernetes)
     - Add Nexus credentials
     - Configure SonarQube server
     - Create pipeline job pointing to GitHub

  2. Configure SonarQube:
     - Create project: tpFoyer
     - Generate token for Jenkins
     - Set quality gates

  3. Configure Nexus:
     - Create maven-releases repository
     - Create maven-snapshots repository
     - Note credentials for Jenkins

  4. Enable Kubernetes:
     - Docker Desktop → Settings → Kubernetes → Enable
     - Wait for Kubernetes to start
     - Verify: kubectl cluster-info

  5. Deploy to Kubernetes:
     - kubectl apply -f k8s/mysql-pv.yaml
     - kubectl apply -f k8s/mysql-deployment.yaml
     - kubectl apply -f k8s/app-deployment.yaml

  6. Set up GitHub webhook:
     - GitHub Repo → Settings → Webhooks
     - Add Jenkins URL
     - Enable automatic builds

  7. Run first pipeline:
     - Jenkins → tpFoyer-Pipeline → Build Now
     - Monitor execution
     - Verify deployment
